# Windows 11 Quick Link Menu (Win + X) Shortcuts Reference

| Menu Item (en_US) | Menu Accelerator (`Win + X`, ...) | Global Windows 11 Shortcut | Notes |
| :--- | :---: | :---: | :--- |
| **Installed apps** | **F** | — | Formerly *Apps and Features* in Windows 10 (hence the `F` key) |
| **Mobility Center** | **B** | — | Shown only on laptops / devices with a battery |
| **Power Options** | **O** | — | Opens *Power & battery* settings |
| **Event Viewer** | **V** | — | Opens `eventvwr.msc` |
| **System** | **Y** | `Win + Pause` | Opens *About* system settings |
| **Device Manager** | **M** | — | Opens `devmgmt.msc` |
| **Network Connections** | **W** | — | Opens *Network & internet* settings |
| **Disk Management** | **K** | — | Opens `diskmgmt.msc` |
| **Computer Management** | **G** | — | Opens `compmgmt.msc` |
| *— Separator —* | | | |
| **Terminal** | **I** | — | Formerly *Command Prompt* (`C`) in early Windows 10 builds |
| **Terminal (Admin)** | **A** | — | Launches Terminal elevated |
| *— Separator —* | | | |
| **Task Manager** | **T** | `Ctrl + Shift + Esc` | Also accessible via `Ctrl + Alt + Del` |
| **Settings** | **N** | `Win + I` | Opens Windows Settings |
| **File Explorer** | **E** | `Win + E` | Opens File Explorer |
| **Search** | **S** | `Win + S` (or `Win + Q`) | Opens Windows Search |
| **Run** | **R** | `Win + R` | Opens the Run dialog |
| *— Separator —* | | | |
| **Shut down or sign out** ▸ | **U** | — | Opens the power submenu |
| ↳ **Sign out** | **U → I** | — | Signs out the current user |
| ↳ **Sleep** | **U → S** | — | Puts the PC to sleep |
| ↳ **Hibernate** | **U → H** | — | Shown if hibernation is enabled |
| ↳ **Shut down** | **U → U** | — | Shuts down the PC (`Win + X`, `U`, `U`) |
| ↳ **Restart** | **U → R** | — | Restarts the PC (`Win + X`, `U`, `R`) |
| **Desktop** | **D** | `Win + D` | Minimizes / restores all open windows |
